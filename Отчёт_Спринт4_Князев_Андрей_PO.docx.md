# **Итог**

В спринте 4 приняты требования к расчётам и аналитике, согласована формулировка про среднее арифметическое и описан калькулятор среднего по усложнению; подготовлены критерии приёмки.

# **Что сделано**

* Зафиксировал правила: среднее \= сумма ÷ количество, два знака, запятая; общий средний по всем оценкам; при отсутствии оценок показывается «—» и сообщение.  
* Согласовал формулировку на главной: «среднее арифм. по записям» (веса не реализованы), как требует задание.  
* Описал требования к фильтрам (дисциплина, период, тип работы), сортировке (дата, значение) и динамике (средние по месяцам и изменение).  
* Описал усложнение «сценарный прогноз» как калькулятор среднего: выбор числа оценок 2, 3, 4, 5, средний балл, сценарии для следующей оценки 3, 4, 5; взвешенный балл отложен до согласования весов.  
* Определил критерии приёмки спринта 4 по контрольному набору: 4,60 / 4,00 / 2,67 / 5,00, общий 4,07, динамика \+0,17.  
* Начал сверку стиля экранов с макетом (docs/design.md).

# **Проблемы и решения**

* Решение по весам: в базовой версии все оценки равны, взвешенный балл — отдельное расширение, поэтому в калькуляторе показан только обычный средний.  
* Открытый вопрос: показывать ли в динамике месяцы без оценок — пока пропускаются.
