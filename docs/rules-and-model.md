# Правила оценивания, расчёты и модель данных

## Правила
| Правило | Решение |
| --- | --- |
| Допустимый диапазон | Целое от 2 до 5. Пусто, буквы, дроби и числа вне диапазона отклоняются: «Оценка должна быть от 2 до 5» |
| Средний по дисциплине | Сумма оценок ÷ количество. Пример: 5, 4, 3, 5 → 17 ÷ 4 = 4,25 |
| Общий средний | Сумма всех оценок ÷ число всех оценок (не среднее средних). Подпись «среднее арифметическое по записям» |
| Округление и вид | Два знака, HALF_UP, запятая; один форматтер на приложение (`AverageFormatter`) |
| Нет оценок | Без деления на ноль: «—» и «Оценок пока нет». Такая дисциплина не подсвечивается и не входит в общий средний |
| Низкий балл | Средний ниже 3,50 — красная подсветка (константа в `GradeRules`) |
| Периоды динамики | Календарные месяцы; месяц без оценок пропускается |
| Удаление дисциплины | Запрещено, если у неё есть оценки: «Сначала удалите оценки (N)» |
| Вес оценок | Все оценки одинаковы; веса — отдельное согласованное расширение |

## Калькулятор цели
Нужная оценка = цель × (n + 1) − сумма, где n — число текущих оценок; дробный результат округляется вверх.
- результат ≤ 2 → «Цель достигнута даже с оценкой 2»;
- результат > 5 → «Цель недостижима одной оценкой (нужно N)»;
- цель вне 2–5 → ввод отклоняется.

Пример: оценки 5, 4, 3, 5 (сумма 17, n = 4). Цель 4,40 → 4,4 × 5 − 17 = 5 → нужна 5. Цель 4,50 → 5,5 → недостижима.

## Модель данных
| Сущность | Поля | Связь |
| --- | --- | --- |
| Discipline | id, name, teacherName (необязательно) | 1 — N Grade |
| Grade | id, disciplineId, value (2–5), date, workType, comment | N — 1 Discipline |

Реализация расчётов: `domain/GradeCalculator.kt`; тесты: `app/src/test/.../GradeCalculatorTest.kt`.

## Хранение (спринт 2)
Модель реализована в Room: см. docs/db-schema.md. Дата хранится числом дней, тип работы — именем константы; удаление дисциплины с оценками запрещено на уровне внешнего ключа (RESTRICT) и проверяется в репозитории.
