# Проверка сохранения данных после перезапуска

Контрольная точка спринта 2: создание дисциплины и оценки, изменение и удаление записи, сохранение после перезапуска.

## Автоматическая проверка
`app/src/androidTest/.../AppDatabaseTest.kt` (эмулятор или устройство, ПКМ → Run):

| Тест | Что проверяет |
| --- | --- |
| discipline_create_read_update_delete | создание, чтение, изменение, удаление дисциплины |
| grade_create_read_update_delete | то же для оценки, дата и тип сохраняются |
| one_discipline_has_many_grades | связь 1 — N |
| grade_with_unknown_discipline_is_rejected | оценка без дисциплины не сохраняется |
| discipline_with_grades_cannot_be_deleted | запрет удаления дисциплины с оценками |
| empty_discipline_can_be_deleted | пустую дисциплину удалить можно |
| seed_loads_test_data_once | тестовые данные: 4 дисциплины, 14 оценок, без дублей |
| data_survives_database_reopen | закрыть базу, открыть заново — данные на месте |

## Ручная проверка в приложении
1. Первый запуск: на главной общий средний **4,07**, **14 оценок**, 4 дисциплины (История — красная).
2. «Предметы» → Математика → «+» → оценка 3, дата сегодня, «Сохранить». В списке новая оценка, средний Математики стал **4,33**.
3. Тап по этой оценке → поменять на 5 → «Сохранить». Средний стал **4,67**.
4. Тап по этой оценке → «Удалить» → «Удалить» в диалоге. Оценка исчезла, средний снова **4,60**.
5. Добавить ещё одну оценку (например, 5) и **полностью закрыть приложение** (смахнуть из недавних).
6. Открыть приложение заново: добавленная оценка на месте, тестовые данные не задвоились (по-прежнему 4 дисциплины).
7. Для чистого повтора: Настройки → Приложения → Успеваемость → Хранилище → Очистить данные.

Результат каждого шага отмечает QA в отчёте спринта.
