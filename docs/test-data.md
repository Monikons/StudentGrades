# Контрольный набор для проверки расчётов

| Данные | Что проверяем | Ожидаемый результат |
| --- | --- | --- |
| 5, 4, 3, 5 | Средний по дисциплине | 4,25 |
| 5, 4, 3, 5 + цель 4,40 | Нужная оценка | 5 |
| 5, 4, 3, 5 + цель 4,50 | Недостижимо (5,5) | Сообщение «недостижима» |
| 4, 4, 4, 4 + цель 4,20 | Нужная оценка (4,2 × 5 − 16) | 5 |
| нет оценок | Средний | «—», без ошибки |
| 2, 2, 2 | Средний и подсветка | 2,00, красная |
| 5, 5, 4 | Округление 14 ÷ 3 | 4,67 |
| 5 + 2, 2, 2, 2 | Общий средний, не среднее средних | 2,60 |
| 7 в поле оценки | Валидация | «Оценка должна быть от 2 до 5» |
| пустая дата | Валидация | «Укажите дату» |
| цель 5,50 | Валидация цели | Ввод отклонён |

Эти же значения проверяют юнит-тесты в `app/src/test`.
