# Паспорт приложения

**Назначение.** Студент вносит учебные оценки, видит средний балл по каждой дисциплине и в целом, следит за динамикой и узнаёт, какая оценка нужна для целевого среднего.

**Главный экран (экран 1):**
- общий средний балл, подпись «среднее арифметическое по записям»;
- количество оценок;
- сводка по дисциплинам: название, число оценок, средний балл;
- дисциплины с низким баллом (< 3,50) выделены красным;
- нижняя навигация: Главная, Предметы, Динамика, Цель.

**Обязательный функционал:** главный экран; список дисциплин; экран дисциплины; добавление, редактирование, удаление оценки; средние баллы; проверка диапазона 2–5; пустые состояния.

**Дополнительно:** фильтры (дисциплина, период, вид работы); динамика по месяцам; калькулятор цели; сортировка; подсветка низкого балла.

**Вне рамок спринта 1:** код, база данных, расчёты в приложении.
