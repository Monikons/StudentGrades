# User Stories

Командный проект «Личный кабинет успеваемости студента»

Формат: **Как** [роль] **я хочу** [цель], **чтобы** [ценность].

---

## US-1. Общая сводка успеваемости

**Как** студент,  
**я хочу** при открытии приложения сразу видеть общий средний балл, количество оценок и краткую сводку по дисциплинам,  
**чтобы** быстро понять текущее состояние успеваемости.

**Критерии приёмки:**
- На главном экране отображаются общий средний балл и число оценок.
- Есть краткий список дисциплин со средним баллом.
- При отсутствии оценок показывается понятное пустое состояние.

**Спринт:** 3

---

## US-2. Просмотр оценок по дисциплине

**Как** студент,  
**я хочу** выбрать дисциплину и увидеть список всех оценок по ней (дата, тип работы, значение, комментарий),  
**чтобы** разобраться, из чего сложился средний балл.

**Критерии приёмки:**
- Тап по дисциплине открывает экран со списком оценок.
- В списке видны: значение, дата, тип работы, комментарий.
- Отображается средний балл по выбранной дисциплине.

**Спринт:** 3

---

## US-3. Добавление новой оценки

**Как** студент,  
**я хочу** добавить новую оценку с указанием дисциплины, значения, даты, типа работы и комментария,  
**чтобы** вести актуальный учёт результатов.

**Критерии приёмки:**
- Есть форма с полями: дисциплина, оценка, дата, тип работы, комментарий.
- Обязательные поля проверяются.
- Оценка принимается только в диапазоне 2–5.
- После сохранения оценка появляется в списке, средний балл пересчитывается.

**Спринт:** 3

---

## US-4. Редактирование и удаление оценки

**Как** студент,  
**я хочу** исправить ошибочно внесённую оценку или удалить запись,  
**чтобы** данные в приложении оставались корректными.

**Критерии приёмки:**
- Из списка оценок можно открыть форму редактирования.
- Изменения сохраняются в базе.
- Удаление убирает запись и пересчитывает средний балл.
- Есть подтверждение удаления.

**Спринт:** 3

---

## US-5. Расчёт среднего балла

**Как** студент,  
**я хочу** видеть средний балл по каждой дисциплине и общий средний балл,  
**чтобы** понимать свою успеваемость без ручных подсчётов.

**Критерии приёмки:**
- Средний по дисциплине = сумма оценок / количество оценок.
- Общий средний считается по всем оценкам (не среднее средних).
- При отсутствии оценок деления на ноль нет, показывается понятное сообщение.
- Отображение единообразное (два знака после запятой).

**Спринт:** 4

---

## US-6. Фильтрация и сортировка оценок

**Как** студент,  
**я хочу** фильтровать оценки по дисциплине, периоду и типу работы, а также сортировать их по дате или значению,  
**чтобы** быстро находить нужные записи.

**Критерии приёмки:**
- Есть фильтр по типу работы и периоду (месяц).
- Можно переключать сортировку: по дате / по значению.
- Пустой результат фильтра показывает понятное сообщение.

**Спринт:** 4

---

## US-7. Калькулятор целевого балла

**Как** студент,  
**я хочу** задать желаемый средний балл и узнать, какая оценка нужна за следующую работу,  
**чтобы** понимать, достижима ли цель одной следующей оценкой.

**Критерии приёмки:**
- Пользователь выбирает дисциплину и вводит целевой средний балл.
- Приложение рассчитывает требуемую следующую оценку.
- Если цель недостижима в диапазоне 2–5, показывается понятное сообщение.
- Если цель уже достигнута даже с минимальной оценкой — сообщается об этом.

**Спринт:** 5

---

## US-8. Пустые состояния и валидация ввода

**Как** студент,  
**я хочу** видеть понятные сообщения, когда оценок или дисциплин ещё нет, и получать ошибки при некорректном вводе,  
**чтобы** не допускать ошибок в данных и понимать, что делать дальше.

**Критерии приёмки:**
- Пустой список оценок: «Оценок пока нет» + кнопка добавления.
- Оценка вне 2–5: сообщение «Оценка должна быть от 2 до 5».
- Пустые обязательные поля блокируют сохранение и показывают ошибку.

**Спринт:** 3
