# Пользовательские сценарии и критерии приёмки

**С-1. Студент открывает приложение и видит общую сводку** (экран 1)
- КП1: на экране общий средний, число оценок и сводка по дисциплинам.
- КП2: без оценок вместо числа «—» и подсказка.
- КП3: дисциплины со средним ниже 3,50 выделены.

**С-2. Студент выбирает дисциплину и просматривает оценки** (1 → 2 → 3)
- КП1: тап по дисциплине открывает список её оценок.
- КП2: запись показывает значение, дату, вид работы, комментарий.
- КП3: в заголовке — средний балл дисциплины.
- КП4: пустая дисциплина → экран 10.

**С-3. Студент добавляет оценку с датой и типом работы** (3 → 4 → 3)
- КП1: форма содержит дисциплину, оценку, дату, тип, комментарий.
- КП2: оценка вне 2–5 или пустая дата не сохраняются, показана причина (экран 9).
- КП3: после сохранения оценка в списке, средний пересчитан.

**С-4. Студент исправляет оценку или удаляет запись** (3 → 4 → 5)
- КП1: тап по оценке открывает форму с заполненными полями.
- КП2: правка меняет запись без дубликата.
- КП3: удаление только после подтверждения; «Отмена» ничего не меняет.
- КП4: после правки или удаления средние пересчитаны.

**С-5. Студент фильтрует оценки за период** (3 → 8 → 3)
- КП1: фильтр по дисциплине, периоду и виду работы.
- КП2: в списке только подходящие оценки.
- КП3: «Сбросить» возвращает полный список.
- КП4: если ничего не найдено — «Ничего не найдено».
- КП5: сортировка по дате и по значению.

**С-6. Студент смотрит динамику и задаёт целевой средний** (1 → 6 → 7)
- КП1: «Динамика» показывает средний по месяцам и изменение к прошлому периоду.
- КП2: калькулятор считает нужную оценку по формуле из docs/rules-and-model.md.
- КП3: если нужна оценка выше 5 — сообщение, что цель недостижима одной оценкой.
- КП4: цель вне 2–5 не принимается.
