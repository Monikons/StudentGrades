Что готово
Спринт 1: паспорт, перечень экранов, сценарии, правила расчётов, граф переходов и прототип (HTML для Figma), структура проекта.

Спринт 2: Room (Entity, DAO, база), операции добавления, чтения, изменения и удаления дисциплин и оценок, тестовые данные, проверка сохранения после перезапуска, тема и общие элементы по макету. Для проверки базы есть служебный экран.

Спринт 3: главный экран со списком дисциплин, переход к дисциплине, список оценок (значение, дата, тип работы, комментарий), форма добавления с проверкой полей и диапазона 2–5, редактирование и удаление оценки с подтверждением, сообщения об ошибках и пустых списках.

Спринт 4: расчёты среднего балла, фильтры, сортировка, динамика; калькулятор среднего балла.

Спринт 5: калькулятор целевого балла (второй режим на экране «Калькулятор» рядом со «Средним баллом»), подсветка низкого среднего (ниже 3,50 — красным, нет оценок — серая «—», граница не низкая), сообщения о неверном вводе и трёх исходах цели (нужна оценка / уже достигнута / недостижима одной оценкой), сохранность ввода, тестирование.

Дальше: спринт 6 — финальная подготовка, презентация и итоговая сводка, приём исправлений после тестирования. В бэклоге остаётся взвешенный средний (веса типов работ) — до согласования весов.

Как открыть и проверить
Android Studio (версия, поддерживающая AGP 9.4). File → Open → папка проекта, дождаться Gradle Sync.

Версии сборки: Gradle 9.9.1, Android Gradle Plugin 9.4.1, Kotlin 2.2.10, KSP 2.3.6, Room 2.8.5 (см. build.gradle.kts и gradle/wrapper). Gradle JDK — по настройкам проекта (gradle/gradle-daemon-jvm.properties).

Запуск на эмуляторе или устройстве: главный экран → «Проверка базы данных (спринт 2)». Полный сценарий спринта 3: открыть дисциплину → «+» → добавить оценку → тап по оценке → изменить → «Удалить» → «Удалить» в диалоге. Порядок проверки — docs/persistence-check.md.

Проверка спринта 5: экран «Калькулятор» → режим «Целевой балл» → ввести цель и текущие оценки → сверить исход и сообщение; на главном экране проверить подсветку среднего (ниже 3,50 — красный, нет оценок — «—»). Контрольные значения — docs/average-check.md, демонстрация — docs/demo-scenario.md (11 шагов).

Юнит-тесты валидации: app/src/test. Тесты базы данных: app/src/androidTest (нужен эмулятор).
