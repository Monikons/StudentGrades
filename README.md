Android-приложение (Kotlin, Jetpack Compose, Room). Командный проект, 6 спринтов. **Сейчас: спринт 3 — экран дисциплин и журнал оценок.**

## Что готово
- **Спринт 1:** паспорт, перечень экранов, сценарии, правила расчётов, граф переходов и прототип (HTML для Figma), структура проекта.
- **Спринт 2:** Room (Entity, DAO, база), операции добавления, чтения, изменения и удаления дисциплин и оценок, тестовые данные, проверка сохранения после перезапуска, тема и общие элементы по макету. Для проверки базы есть служебный экран.
- **Спринт 3:** главный экран со списком дисциплин, переход к дисциплине, список оценок (значение, дата, тип работы, комментарий), форма добавления с проверкой полей и диапазона 2–5, редактирование и удаление оценки с подтверждением, сообщения об ошибках и пустых списках.
- **Дальше:** спринт 4 — расчёты, фильтры, сортировка, динамика; спринт 5 — калькулятор цели, подсветка низкого балла и тестирование. В этой сборке их нет.

## Как открыть и проверить
1. Android Studio (версия, поддерживающая AGP 9.4). File → Open → папка проекта, дождаться Gradle Sync.
2. Версии сборки: Gradle 9.9.1, Android Gradle Plugin 9.4.1, Kotlin 2.2.10, KSP 2.3.6, Room 2.8.5 (см. `build.gradle.kts` и `gradle/wrapper`). Gradle JDK — по настройкам проекта (`gradle/gradle-daemon-jvm.properties`).
3. Запуск на эмуляторе или устройстве: главный экран → «Проверка базы данных (спринт 2)». Полный сценарий спринта 3: открыть дисциплину → «+» → добавить оценку → тап по оценке → изменить → «Удалить» → «Удалить» в диалоге. Порядок проверки — docs/persistence-check.md.
4. Юнит-тесты валидации: `app/src/test`. Тесты базы данных: `app/src/androidTest` (нужен эмулятор).

## Структура
```
app/src/main/java/com/example/studentgrades/
  StudentGradesApp.kt      # создаёт БД и репозиторий
  MainActivity.kt
  data/
    local/                 # Room: DisciplineEntity, GradeEntity, DAO, AppDatabase, Converters, Mappers
    repository/            # GradeRepository: добавление, чтение, изменение, удаление; тестовые данные
    TestData.kt            # тестовые данные (docs/test-data.md)
    AppData.kt             # снимок данных для экранов
  domain/                  # правила, модели, валидация ввода (чистый Kotlin)
  ui/
    theme/                 # цвета макета
    components/            # общие элементы по макету: заголовок, строка, плашка, кнопка
    navigation/            # маршруты и граф переходов
    dbcheck/               # служебный экран проверки базы (спринт 2)
    AppViewModel.kt        # данные из БД, сохранение и удаление оценок, операции экрана проверки
    home/ grades/ gradeform/                       # экраны спринта 3: список дисциплин, оценки, форма
app/src/test/              # юнит-тесты валидации (JVM)
app/src/androidTest/       # тесты БД: CRUD, связь 1—N, перезапуск
docs/                      # документация и прототип
```

## Ветки и коммиты
`main` — стабильная версия, `develop` — интеграция, задачи — в `feature/<кратко>`. Слияние в `develop` делает Lead Developer.
